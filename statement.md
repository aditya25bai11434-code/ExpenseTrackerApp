# Project Statement

## Problem Statement
Students and individuals often struggle to keep track of daily localized expenses (like food, transport, and academics) due to complex financial tools.

## Scope
A simple, robust desktop solution developed in Java Swing providing CRUD operations for daily expense logging, automatic calculations, and local data persistence.

## Target Users
- College Students
- Individuals seeking lightweight budget tracking

## High-Level Features
- Dynamic expense logging with input validation
- Live expenditure totals calculation
- File-based persistence (`expenses.txt`)
- Real-time row deletion and dynamic summary adjustment
